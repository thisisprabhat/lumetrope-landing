# Version history

Lumetrope has built-in local version control: save versions, restore any of them, branch and diff. It is stored with autosave in your browser (IndexedDB), with no server.

## How do I save a version?

Press <kbd>Alt</kbd>+<kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd>, or ask an agent to use `save_version`. Give it a message that says what changed.

## How do I restore an older one?

Open the history, pick a version and restore it. Unsaved work is first kept as an Auto-saved version, so restoring never loses anything.

## Is history shared or backed up?

No. It lives in this browser's storage on this device. Clearing site data removes it; keep important work saved to a file too.
