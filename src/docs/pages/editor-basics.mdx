# Editor basics

The Lumetrope editor has a layers pane on the left, the canvas in the middle, properties on the right and a keyframe timeline along the bottom. Drag any pane edge to resize it, and double-click an edge to reset it.

## What tools are there?

| Tool | Key |
|---|---|
| Select | <kbd>V</kbd> |
| Rectangle | <kbd>R</kbd> |
| Ellipse | <kbd>O</kbd> |
| Pen | <kbd>P</kbd> |
| Text | <kbd>T</kbd> |
| Hand (pan) | <kbd>H</kbd> or hold <kbd>Space</kbd> |

All shortcuts are listed in [Keyboard shortcuts](/docs/keyboard-shortcuts/).

## How do I play and scrub?

Tap <kbd>Space</kbd> to play or pause. Step frames with <kbd>,</kbd> and <kbd>.</kbd>. Press <kbd>F</kbd> for the full-screen player, which supports scrubbing, speed, backgrounds and clickable state machines.

## How do I edit layers?

Select layers in the layers pane or on the canvas. Copy, cut, paste, duplicate and delete work as usual, and <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>G</kbd> groups layers into a nested scene. Right-click for context menus. Align, distribute, snapping and a grid are available, and undo and redo cover every change.

## Can I make quick edits to an existing file?

Yes. Recolour every colour globally, and change the canvas size, frame rate or duration from the file info.
