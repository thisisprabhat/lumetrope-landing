# Install on macOS

Download the `.dmg` that matches your Mac, open it and drag Lumetrope to Applications. Lumetrope runs on macOS 11 Big Sur or newer, on Apple Silicon and Intel.

## Which download do I need?

| Mac | File |
|---|---|
| Apple Silicon (M1 and later) | `Lumetrope_<version>_aarch64.dmg` |
| Intel | `Lumetrope_<version>_x64.dmg` |

Find them on the project's GitHub Releases page. Not sure which Mac you have? Apple menu, About This Mac.

## Why does Gatekeeper say it cannot open Lumetrope?

Builds that are not notarized trigger Gatekeeper on first launch. Either right-click the app, choose **Open**, then **Open** again, or remove the quarantine flag in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Lumetrope.app
```

You only need to do this once.

## Where does the app keep its data?

Projects and version history live in the app's web storage. Files you open or save stay where you put them; access to them survives restarts. The MCP server is copied to `~/Library/Application Support/app.lumetrope.editor/mcp/lumetrope-mcp.mjs`.
