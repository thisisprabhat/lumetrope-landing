# Projects, saving and files

Lumetrope opens on a dashboard of your projects. Press <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd> to write back to the file you opened, or <kbd>Shift</kbd>+<kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd> to save as a new one.

## What is on the dashboard?

On the left: new project, custom size, canvas presets, open a file, paste Lottie JSON, new from SVG, samples, and connect an AI agent. On the right: every project you created, opened, edited, previewed or exported, with thumbnails, search and filters.

## Where do my files live?

| Where | How access is remembered |
|---|---|
| Desktop app | File paths; access survives restarts |
| Chrome and Edge | File System Access handles |
| Other browsers | A cached copy in the browser |

If a file changes outside Lumetrope, the change is picked up when you reopen it and kept in [version history](/docs/version-history/).

## Can I link directly to a file?

In a dev or self-hosted copy, open `/?open=/samples/shapes.json` style URLs to load a file on start.
