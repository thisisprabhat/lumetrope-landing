# Keyboard shortcuts

Lumetrope uses ⌘ (Cmd) on macOS and Ctrl on Windows and Linux. Menus always show the right labels for your system. Shortcuts are inactive while you type in a text field and on the dashboard, which only knows New and Open.

The single-key tool shortcuts (V, R, O, P, T, H) work only in Animate mode.

## What are the tool and playback shortcuts?

| Action | macOS | Windows / Linux |
|---|---|---|
| Select, rectangle, ellipse, pen, text, hand | <kbd>V</kbd> <kbd>R</kbd> <kbd>O</kbd> <kbd>P</kbd> <kbd>T</kbd> <kbd>H</kbd> | <kbd>V</kbd> <kbd>R</kbd> <kbd>O</kbd> <kbd>P</kbd> <kbd>T</kbd> <kbd>H</kbd> |
| Play / pause (tap), pan (hold) | <kbd>Space</kbd> | <kbd>Space</kbd> |
| Previous / next frame | <kbd>,</kbd> <kbd>.</kbd> | <kbd>,</kbd> <kbd>.</kbd> |
| Jump to the first / last frame of the play range (in/out point) | <kbd>Home</kbd> <kbd>End</kbd> | <kbd>Home</kbd> <kbd>End</kbd> |
| Play full screen | <kbd>F</kbd> | <kbd>F</kbd> |

## What are the editing shortcuts?

| Action | macOS | Windows / Linux |
|---|---|---|
| Undo | <kbd>⌘Z</kbd> | <kbd>Ctrl+Z</kbd> |
| Redo | <kbd>⇧⌘Z</kbd> | <kbd>Ctrl+Shift+Z</kbd> or <kbd>Ctrl+Y</kbd> |
| Copy, cut, paste | <kbd>⌘C</kbd> <kbd>⌘X</kbd> <kbd>⌘V</kbd> | <kbd>Ctrl+C</kbd> <kbd>Ctrl+X</kbd> <kbd>Ctrl+V</kbd> |
| Duplicate | <kbd>⌘D</kbd> | <kbd>Ctrl+D</kbd> |
| Delete | <kbd>⌫</kbd> | <kbd>Backspace</kbd> / <kbd>Delete</kbd> |
| Select all | <kbd>⌘A</kbd> | <kbd>Ctrl+A</kbd> |
| Nudge selection 1 px (10 px with Shift) | <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> |
| Group into nested scene | <kbd>⌘G</kbd> | <kbd>Ctrl+G</kbd> |

## What are the zoom and file shortcuts?

| Action | macOS | Windows / Linux |
|---|---|---|
| Zoom in / out | <kbd>⌘+</kbd> <kbd>⌘−</kbd> | <kbd>Ctrl++</kbd> <kbd>Ctrl+−</kbd> |
| Fit to window | <kbd>⌘0</kbd> | <kbd>Ctrl+0</kbd> |
| Fit to window / zoom to 100% / zoom to selection | <kbd>⇧1</kbd> <kbd>⇧0</kbd> <kbd>⇧2</kbd> | <kbd>Shift+1</kbd> <kbd>Shift+0</kbd> <kbd>Shift+2</kbd> |
| Save to file | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |
| Save as | <kbd>⇧⌘S</kbd> | <kbd>Ctrl+Shift+S</kbd> |
| Save version | <kbd>⌥⌘S</kbd> | <kbd>Ctrl+Alt+S</kbd> |
| New, open, export | <kbd>⌘N</kbd> <kbd>⌘O</kbd> <kbd>⌘E</kbd> | <kbd>Ctrl+N</kbd> <kbd>Ctrl+O</kbd> <kbd>Ctrl+E</kbd> |
