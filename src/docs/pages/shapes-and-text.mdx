# Shapes, pen tool and text

Lumetrope draws rectangles, ellipses, polygons and stars, plus bezier paths with the pen tool, text, images, and imported SVG or Lottie. Each shape can have fills, strokes and gradients.

## What shapes can I draw?

Rectangle (<kbd>R</kbd>), ellipse (<kbd>O</kbd>), polygon and star, and freeform paths with the pen (<kbd>P</kbd>) using bezier handles. Solids and null layers are available too, and layers can be parented.

## How do I style a shape?

- **Fills and strokes:** colour, plus caps, joins and dashes for strokes.
- **Gradients:** linear and radial.
- **Path modifiers:** trim paths, round corners and repeaters.

## How do I add text, images and SVG?

Use the text tool (<kbd>T</kbd>) for text. Drop an image or `.svg` file on the canvas, or choose **New from SVG** on the dashboard. You can also import an existing Lottie file.
