# Getting started

Lumetrope is an open-source editor for Lottie and dotLottie animations that runs in your browser and as a native app for macOS, Windows and Linux. The fastest start is the web app: open it and drop a file on the canvas.

## How do I install Lumetrope?

Pick one:

- **Web app:** nothing to install. See [Use the web app](/docs/web-app/).
- **macOS:** [Install on macOS](/docs/install-macos/).
- **Windows:** [Install on Windows](/docs/install-windows/).
- **Linux:** [Install on Linux](/docs/install-linux/).

## How do I open my first animation?

1. Use **File, Open**, or drop a `.json`, `.lottie` or `.svg` file on the canvas.
2. Or start from the dashboard: **New project**, a canvas preset, **Paste Lottie JSON**, **New from SVG**, or one of the interactive samples.
3. Press <kbd>Space</kbd> to play and pause. Press <kbd>F</kbd> for full-screen playback.

## What can I do next?

- Learn the panes and tools in [Editor basics](/docs/editor-basics/).
- Add motion with [keyframes and easing](/docs/animating/).
- Make it respond to clicks and hovers with [state machines](/docs/state-machines/).
- Ship it with [Exporting](/docs/exporting/).
- Let an AI agent help: [Connect AI agents with MCP](/docs/mcp/).
